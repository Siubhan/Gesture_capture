# Gesture FX

Жест перед камерой запускает анимацию поверх видео. Работает на **OpenCV + MediaPipe**, в реальном времени на обычной веб-камере, без GPU.

## Жесты

| Жест | Что происходит |
|------|----------------|
| Открытая ладонь (`Open_Palm`) | Конфетти |
| Кулак (`Closed_Fist`) | Взрыв с ударной волной |
| Два пальца буквой V (`Victory`) | Фейерверк |
| Палец-пистолет (две вариации, см. ниже) | Выстрел: вспышка, трассер, отдача, звук |
| Сердечко двумя руками | Лицо превращается в жабу (Pepe) |

**Пистолет** распознаётся собственным правилом по точкам руки (в MediaPipe такого жеста нет). Работают две вариации:

1. указательный вытянут, большой отведён, остальные согнуты;
2. указательный и средний вытянуты и прижаты друг к другу («два пальца»), большой отведён, безымянный и мизинец согнуты. От Victory отличается сомкнутыми пальцами и отведённым большим.

Выстрел вылетает из кончика указательного пальца туда, куда он направлен. Если палец направлен прямо в камеру, выстрел превращается в большую вспышку на весь экран.

**Сердечко:** кончики указательных пальцев сходятся сверху, кончики больших снизу, запястья разведены. Пока держите сердечко и ещё полторы секунды после, вместо лица в кадре жаба. Она поворачивается и масштабируется вместе с головой. Остальные жесты на время сердечка отключены.

## Установка и запуск

```bash
pip install -r requirements.txt
python gesture_fx.py
```

| Параметр | Что делает |
|----------|-----------|
| `--camera N` | Взять камеру с индексом N (по умолчанию автопоиск 0-5; на Windows используется DirectShow) |
| `--mute` | Отключить звук выстрела |
| `--profile` | При выходе напечатать среднее время каждого этапа кадра и FPS |

Клавиши: `q` / `Esc` выход, `l` показать или скрыть точки руки.

Модели MediaPipe скачиваются автоматически в папку `models/` при первом запуске. Эту папку не нужно коммитить: добавьте строку `models/` в `.gitignore`.

Если камера не находится: проверьте Параметры Windows → Конфиденциальность → Камера (разрешите доступ классическим приложениям) и закройте программы, которые её занимают (Zoom, Teams, OBS, браузер).

## Структура

```
gesture_fx.py     главный цикл: камера, MediaPipe, связка жестов с эффектами
gestures.py       правила жестов (пистолет, сердечко), дебаунс, данные о руке
effects.py        частицы, вспышки, трассер, свечение, тряска экрана
faceswap.py       замена лица картинкой по ключевым точкам детектора лиц
sound.py          синтез и проигрывание звука выстрела
assets/pepe.png   картинка жабы с прозрачностью
benchmark.py      замеры производительности
tests/            автотесты (pytest)
```

## Настройка

Пороги в начале `gestures.py`:

- `HOLD_FRAMES`: сколько кадров подряд жест должен держаться, прежде чем сработать.
- `GUN_INDEX_EXT`, `GUN_CURL`, `GUN_THUMB`, `GUN_PAIR`: пороги пистолета. Если жест срабатывает плохо или слишком часто, подкрутите их (пояснения в комментариях). Расстояния считаются в 3D от запястья, в долях длины ладони.
- `HEART_TOUCH`, `HEART_HEIGHT`, `HEART_WRIST`: пороги сердечка.

Паузы между срабатываниями и подписи в окне заданы в таблице `GESTURES` в `gesture_fx.py`. Подписи только латиницей: шрифты OpenCV не умеют кириллицу.

### Своя картинка вместо жабы

1. Подготовьте PNG с прозрачностью (канал alpha) и положите как `assets/pepe.png`.
2. В `faceswap.py` поправьте `SPRITE_EYES`: координаты центров глаз на вашей картинке в пикселях.

Глаза на картинке будут совмещены с глазами человека, поэтому лучше брать голову анфас.

### Свой жест

В MediaPipe есть ещё `Thumb_Up`, `Thumb_Down`, `Pointing_Up` и `ILoveYou`. Чтобы привязать к ним анимацию, добавьте метод в класс `FX` (принимает `hand`) и строку в таблицу `GESTURES`. Для совсем своего жеста напишите правило по образцу `is_gun` и подключите его в `classify`.

## Тесты

```bash
pip install -r requirements-dev.txt
pytest          # 84 теста, меньше секунды
ruff check .    # линтер
```

Покрытие тестами около 94%. Не покрыто то, что требует железа: загрузка настоящих моделей MediaPipe, открытие камеры и платформенные ветки звука. Сквозной цикл `main()` проверяется на поддельной камере и поддельном распознавателе. Тест жеста «пистолет» использует настоящие точки руки, снятые с реального кадра.

## Производительность

Замеры нашей части кадра (кадр 960x540, песочница на CPU, ваши цифры будут другими; запустите `python benchmark.py`):

| Что | Было | Стало |
|-----|------|-------|
| Рендер эффектов, когда на экране ничего нет | 12.3 мс | 0.0001 мс |
| Рендер сцены (330 частиц и колец) | 12.4 мс | 2.2 мс |
| Рендер выстрела с тряской экрана | 14.8 мс | 3.5 мс |
| Распознавание жеста пистолета | 16.4 мкс | 3.2 мкс |
| Замена лица, лицо крупно (глаза 160 px) | 6.0 мс | 1.3 мс |
| Замена лица, лицо обычное (глаза 80 px) | 1.2 мс | 0.5 мс |

Что изменилось: свечение считается на уменьшенной в 4 раза копии слоя, а не на всём кадре; пустой слой не рисуется; слой переиспользуется; тряска экрана делается целочисленным сдвигом вместо `warpAffine`; жаба смешивается с кадром целочисленными операциями OpenCV; детектор лиц запускается только пока жаба на экране. Картинка при этом почти не меняется (PSNR 49.6 дБ относительно старого рендера).

Время самого распознавания рук и лиц зависит от вашего компьютера и в эти цифры не входит. Узнать его, и вообще где у вас уходит время кадра, можно так:

```bash
python gesture_fx.py --profile
```

Поработайте с программой, нажмите `q`, и в консоли появится таблица по этапам (`capture`, `hands`, `logic`, `faceswap`, `effects`, `display`) и итоговый FPS.
